# Folders Cleaner
Clear all files from all folders on current directory path
**WINDOWS ONLY**

## How to

1. Double check the directory of folders you want to clear, once script running there is no way back. File removed is not recoverable
2. For sanity check, use `tree /f` to see all files inside the folder
3. Download `clear-folders.ps1`
4. Open it in notepad or similiar
5. Repalce the line `path` with the directory path you want to clear i.e `D:\Folders1\Folders2`
6. Save and close
7. Run the script
